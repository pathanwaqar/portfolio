# Waqar Pathan Portfolio — Advanced Animation Edition

Responsive, dependency-free portfolio website for Waqar Pathan.

## Included updates

- Added Kiteworks and Health Clinic MD as highlighted previous projects.
- Added detailed project case-study dialogs describing the work completed.
- Added animated network canvas, cursor follower, magnetic buttons, 3D card tilt, parallax, counters, project filtering, animated system orbit, text scramble, scroll reveals and animated project artwork.
- Added `prefers-reduced-motion` support for accessibility.

## Run locally

Open `index.html`, or run:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy

Upload the folder to Vercel, Netlify, GitHub Pages, Cloudflare Pages, or any static web host. No build step is required.

## Main files

- `index.html` — page structure and project content
- `styles.css` — responsive design and animations
- `script.js` — filters, dialogs, counters, network canvas and interactions
- `assets/Waqar-Pathan-Resume.pdf` — downloadable résumé
- `assets/waqar-pathan.png` — profile image extracted from the supplied screenshot
